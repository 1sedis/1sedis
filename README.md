# Пиксельный гамбит

Инкрементальный автобатлер на шахматной доске. Расставляйте фигуры, побеждайте
волны врагов, покупайте улучшения и коронуйтесь ради постоянных бонусов.

## Запуск

```bash
npm install
npm run dev      # дев-сервер на http://localhost:5173
npm test         # юнит-тесты (vitest)
npm run build    # проверка типов и сборка в dist/
```

## Как играть

- Бой идёт сам: белые фигуры стоят в двух нижних рядах, чёрные волны — сверху.
- Каждая фигура ходит и бьёт по-своему: конь прыгает «Г», слон стреляет по
  диагонали, ладья — по прямой, ферзь — во все стороны.
- Три одинаковые фигуры сливаются в одну со звездой (×2 к здоровью и атаке).
- Поражение отбрасывает на волну назад, так что авто-бой фармит золото сам.
- С 15-й волны доступна **коронация**: сброс забега за короны, каждая даёт
  +5% к атаке, здоровью и золоту навсегда.
- Прогресс автоматически сохраняется в браузере.

## Структура

- `src/game/` — логика без DOM: фигуры, бой, экономика, сохранения.
- `src/ui/` — интерфейс, пиксельные спрайты (рисуются кодом), эффекты.
- `tests/` — тесты логики.
