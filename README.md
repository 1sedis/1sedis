# Пиксельный гамбит

Шахматная кампания-автобатлер с idle-доходом. Отвоюйте королевство у Чёрного
короля: расставляйте армию, побеждайте в боях и собирайте казну с захваченных
земель — даже когда игра закрыта.

Играть онлайн: https://1sedis.github.io/1sedis/

## Запуск

```bash
npm install
npm run dev      # дев-сервер на http://localhost:5173
npm test         # юнит-тесты (vitest)
npm run build    # проверка типов и сборка в dist/
```

## Как играть

- **Кампания:** 4 главы по 9 боёв, в конце каждой — босс со своим приёмом и фазой ярости
  (подкрепление, прыжок смерти, обвалы, тёмная корона); удары по площади видны заранее.
- **Король:** пал ваш король — бой проигран, пал вражеский — победа. Короли
  отступают от угроз и прячутся за своими; соседние с королём союзники бьют на 20% сильнее.
- **Роли:** пешки идут только вперёд и закрывают собой выстрелы, дойдя до края
  становятся ферзём; кони прыгают в тыл к стрелкам и королю; слоны, ладьи и
  ферзь стреляют по линиям, которые блокирует любая фигура.
- **Лимит фигур** на бой растёт с главами; **звёзды** — за победу, сохранённого
  короля и малые потери.
- **Лагерь:** найм фигур, улучшение типов, постройки (Казна, Штаб, Кузница).
- **Казна:** каждый пройденный бой приносит золото в минуту, копится офлайн.
- **Реликвии:** за каждого босса и каждые 12 звёзд — выбор 1 из 3 постоянных
  бонусов (18 штук), которые меняют правила боя.
- **Облик:** с 5-го уровня фигуры в стальной броне, с 10-го — в золотой (враги:
  багровые и обсидиановые), так сразу видно силу фигуры.
- **Способности:** на 5-м уровне фигура получает приём — один из двух на выбор
  (например, ладья: «Залп» или «Крепость»), на 10-м он усиливается; враги высоких
  уровней пользуются первым.
- **Элитные враги** со 2-й главы: бронированные, яростные, кровавые, шипастые, быстрые
  и взрывные — свойство видно по значку над фигурой.
- **Ландшафт:** камни и вода перекрывают путь, лес защищает, с холма стрелки бьют
  сильнее; у каждой главы свои карты, в Бездне — случайные.
- **Синергии:** бонусы за состав — Фаланга, Кавалерия, Пара слонов, Башни, Полный набор.
- **Справочник** фигур, приёмов и синергий; реплики Чёрного короля перед главами и боссами.
- **Бездна:** после 2-9 открываются бесконечные этажи с растущими врагами, стражем
  и реликвией каждые 10 этажей; авто-спуск для idle-игры, а пока игра закрыта, армия
  проходит до 10 этажей сама.
  Только здесь добываются **осколки бездны** — за них крутят **Рулетку бездны**:
  случайные вечные улучшения от обычных до легендарных (фениксы-пешки, цепной прыжок
  коня, пронзающий луч слона, теневой двойник ферзя и другие).
- **Новая партия:** после финального босса — сброс за короны и более сильные враги.
  Короны тратятся в **Древе короны**: три ветви доктрин с выбором 1 из 2 на каждом ярусе —
  шахматные приёмы (рокировка, вилка, шах), устройство двора и силы Бездны, а также
  новые фигуры: Архиепископ, Канцлер и Призрак.
- **Разбор боя:** после боя — MVP, урон каждой фигуры, кто и откуда сразил короля и
  советы; при расстановке красным подсвечены клетки, которые простреливает враг;
  «Авто» симулирует 16 расстановок и берёт лучшую. Поражение приносит часть золота
  (по урону врагу) и совет, какое улучшение поможет именно в этом бою.
- **Достижения:** 28 целей с наградами золотом.
- **Сохранение** переносится между устройствами кодом (Настройки → Экспорт / Импорт).
- **Обучение:** подсказки в первых боях, отключаются в настройках.
- **Звук:** 8-битная музыка (темы меню, карты, боя и босса) и эффекты генерируются
  кодом; громкость в настройках, быстрая кнопка звука в верхней панели.

## Структура

- `src/game/` — логика без DOM: фигуры, бой, уровни кампании, экономика, сохранения.
- `src/ui/` — меню, экраны (карта, арена, лагерь), доска, пиксельные спрайты.
- `docs/DESIGN.md` — дизайн-документ.
- `tests/` — тесты логики.
