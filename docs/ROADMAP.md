# План доработки «Пиксельного гамбита»

Составлен по итогам геймдизайн-разбора. Порядок — по влиянию на удержание игрока.
Каждый этап — отдельный коммит с тестами; после этапа пересобрать карточку
(`npm run build:artifact`) и прогнать бота кампании (скрипт ниже).

## Этап 1. Понятные поражения ✅

Проблема: игрок не понимает, почему проиграл; бои детерминированы, «Ещё раз» без
изменений бесполезен. Замер: хорошая расстановка стоит 1–2 уровня прокачки
(2-5: «Авто» побеждает с ур. 6, лучшая случайная — с ур. 4).

- [x] **Статистика боя.** В `Battle` копить по каждому юниту: нанесённый и полученный
  урон, убийства, кто убил. Файлы: `src/game/battle.ts` (в `dealDamage`).
- [x] **Разбор боя** в окне результата (`src/ui/screens/arena.ts`, `showResult`):
  MVP, таблица урона по своим фигурам, причина поражения
  («король пал от ладьи с h8»), 1–2 авто-совета («враг простреливает вертикаль d»).
- [x] **Подсветка угроз** при расстановке: клетки, которые бьют вражеские стрелки и
  кони с исходных позиций (переиспользовать `threatens()` из `battle.ts`), слой в
  `src/ui/board.ts`, переключатель в панели.
- [x] **Улучшить «Авто»** (`src/game/autoformation.ts`): перебрать несколько шаблонов
  расстановки симуляцией и взять лучший (бои дешёвые, ~5 мкс/тик).

## Этап 2. Без стен гринда ✅

Проблема: глава 4 ≈ 70% времени кампании у бота; поражение даёт 0 золота.

- [x] **Утешительная награда** за поражение: до 50% награды за переигровку,
  пропорционально доле снятого здоровья врагов (`enemyDamageShare`, `recordResult`).
  В Бездне так же от награды этажа.
- [x] **Подсказка «что прокачать»**: на экране поражения симуляция пробует +1 уровень
  каждому типу фигур в расстановке и предлагает лучшее улучшение с кнопкой покупки
  (`src/game/advice.ts`). Если улучшение даёт победу, это написано прямо.
- [x] **Пики**: «Бастион» 3-8 был сложнее босса главы (ур. 13 → 12). Новый бот
  (умное «Авто», жадные покупки, реликвии) не застревает больше чем на 6 попыток;
  главная стена теперь финальный босс 4-9.

**Вывод бота (важно для баланса):** с умным «Авто» и жадной прокачкой кампания
проходится за ~1–1,5 ч чистого времени боёв, почти каждый бой с первой попытки:
награды за первое прохождение (×1,2 за уровень) поспевают за ценами улучшений.
Старый бот выходил на 13 ч из-за слабой расстановки и покупок.

**Пересчёт экономики (после этапов 4–6):** награда за первое прохождение
`30 × 1,15^i` вместо `50 × 1,2^i`, чтобы казна снова была главным источником золота;
3-6 → ур. 11, 4-7, 4-8 → 15, 4-9 → 16. Бот: умное «Авто» — 2,3 ч (гл. 2 ≈ 24 мин,
гл. 3 ≈ 1 ч, гл. 4 ≈ 50 мин), простое «Авто» — 3,9 ч; не больше 15 попыток на бой.
Живому игроку с чтением и расстановкой выходит примерно 4–7 ч.

## Как проверять баланс

Реалистичный бот: `scripts/story-bot.test.ts` (`npm run bot:story`, `CHESS=1` — игрок, собирающий
шахматный набор, `MOVES=1` — тратит ходы, `WAIT=1` — ждёт казну между попытками). Проходит карту
забега: в лагерь при потерянных знамёнах, в элиту при двух и более, к торговцу с золотом, в
событиях без риска. Играет партии 1–3 подряд, перенося всё (короны → Древо, осколки → рулетка),
покупает по силе на золото, выбирает реликвии по ценности, спускается в Бездну, когда застрял,
и проходит финал. Первые выводы: «рой пешек» — доминирующая стратегия; финал с реликвиями и рулеткой
слишком лёгкий; вся история ≈ 1,5–2 ч машинного времени. Пешек теперь не больше 8 (как на доске;
лишние в старых сохранениях возвращаются золотом) — эффективный бот добирает коней, но пешки
по-прежнему главная статья расходов.

Бот кампании: `scripts/campaign-bot.test.ts` (запуск: `npm run bot`). Жадно покупает,
ставит армию через `bestFormation` (или `PLAIN=1` — через `autoFormation`), выбирает
реликвии, ждёт казну, печатает время по главам, попытки и таймауты (`TRACE=1` — по уровням,
`GAME=N` — N-я партия с её искажением, без древа и рулетки). Цели: глава 1 ≈ 5–20 мин,
глава 2 ≈ 30–45, глава 3 ≈ 45–60, глава 4 не дольше полутора глав 3, таймаутов 0.
